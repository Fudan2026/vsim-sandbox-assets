# 结果数据集说明（results/export/）

本目录包含案例全部计算结果的结构化导出，与案例正文（main.ipynb）及 run_all.py 的输出**完全同口径**。
所有数字由固定随机种子（20261029）与公开代码生成；运行 `run_all.py` 可在约 1–2 分钟内完整重建；运行 `vx_verify.py` 可得到 24/24 锚点核验。

## 使用建议

1. **快速核查**：任选一个 CSV，对照案例报告中对应表格的数字——应当完全一致（浮点尾数除外）。
2. **二次分析**：所有文件均为 tidy 格式（一行一条记录），可直接 `pd.read_csv()` 后做进一步统计、画图或检验。
3. **课堂演示**：01（净值曲线）、13（IC 序列）适合现场画图；05（成本扫描）适合让学生预测 10bp 处的排序。
4. **重建**：任何一个 CSV 都可由 run_all.py / 案例正文对应单元重新生成；数字不一致时，先检查随机种子是否为 20261029。
